# 🐼 Panda Shopping Website

A simple and clean shopping website built using **HTML and Custom CSS**.
This project demonstrates how a basic e-commerce landing page can be designed using only frontend technologies.

## 🌐 Live Website

https://panda-shopping-site.netlify.app/

## 📌 Project Overview

The Panda Shopping Website is a static e-commerce style webpage where users can explore different products such as shoes, backpacks, watches, and more.
The goal of this project was to practice **HTML layout structuring and custom CSS styling** to create a visually appealing product showcase website.

## 🛠️ Technologies Used

* HTML5
* Custom CSS
* Google Fonts
* Responsive Layout Design

## ✨ Features

* Clean and modern UI design
* Product showcase sections
* Category sections (Shoes, Backpack, etc.)
* Product cards with images, price, and buy button
* Promotional banner section
* Email subscription section
* Fully responsive layout
